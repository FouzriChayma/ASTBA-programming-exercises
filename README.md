# Programming Exercises

A collection of programming exercises and practical projects created as part of my teaching experience, designed to help students develop their programming skills through practice.

## Topics

* Algorithmic problem solving
* Python programming
* HTML5 / CSS3 / JavaScript
* Web development fundamentals

## Purpose

This repository brings together exercises, practical activities, and learning materials designed to make programming easier to understand through hands-on practice.

The goal is to help students strengthen their **logical thinking, problem-solving skills, and programming fundamentals** while progressing from basic concepts to practical applications.

## What You'll Find

* Algorithmic exercises
* Python programming challenges
* Problem-solving activities
* HTML5 / CSS3 exercises
* JavaScript fundamentals
* Small web development projects

> Created with a passion for teaching programming and helping students learn by building and practicing.
